# 🤖 Smart Utility AI Agent

A beginner-friendly Agentic AI project built using:

- FastAPI
- Ollama
- Python Tool Functions
- Prompt-based Tool Routing

This project demonstrates the foundational architecture behind modern AI agents and tool-using LLM systems.

---

# 🚀 Project Overview

This AI agent can:

- Understand user intent
- Decide which tool to use
- Execute tools dynamically
- Return intelligent responses

The project acts as a foundational implementation of Agentic AI systems similar to modern AI copilots and assistants.

---

# 🧠 Features

✅ AI-based tool routing  
✅ Weather tool  
✅ Calculator tool  
✅ Time tool  
✅ Ollama integration  
✅ FastAPI backend  
✅ Modular architecture
